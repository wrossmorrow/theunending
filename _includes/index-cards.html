{%- comment -%} Index list with one thumbnail per entry. One static image rather than a rolling strip: the header ticker already supplies the motion on this page, and the index's job is scanning. A single tile gives the "what does this set look like" signal at a fraction of the weight -- about 2KB a row against roughly 1.2MB for a prebuilt animated strip. Image selection, in order of preference: 1. `thumb:` in the post's front matter -- an id you chose 2. the first id in _data/stream_ids/.json With one tile standing for a whole set, the curated option is worth taking: the first id is whatever sorted first, which may be an outlier. A post with neither renders as a plain row -- no thumbnail, no empty slot.
